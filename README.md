# Architectural Consultation Portal

A comprehensive AI-powered architectural consultation platform for heritage and traditional Indian architecture.

## 🏛️ Features

### Customer Portal
- **Landing Page**: Hero section, architectural styles showcase, process, testimonials, CTA
- **12-Step Wizard**: Card-based requirement gathering (Location, Plot, Purpose, Styles, Floors, Budget, Timeline, Family, Lifestyle, Interior, Requirements, Upload)
- **AI Consultation**: Natural language conversation for requirement gathering
- **Contact & OTP**: Contact form with 6-digit OTP verification
- **Project Summary**: AI-generated summary with lead scoring
- **Booking System**: Consultation booking with calendar

### Admin Portal
- **Dashboard**: Statistics and lead management
- **Lead Tracking**: CRM workflow with lead scoring (0-100)

## 🛠️ Technology Stack

- **Frontend**: Next.js 16, TypeScript, Tailwind CSS 4
- **State**: Zustand with persistence
- **Icons**: Lucide React
- **Styling**: Gradient designs, responsive layouts

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Access at http://localhost:3000
```

## 📱 Pages

- `/` - Landing page
- `/wizard` - 12-step requirement wizard
- `/ai-consultation` - AI chat consultant
- `/contact` - Contact form & OTP
- `/summary` - Project summary
- `/booking` - Consultation booking
- `/admin/login` - Admin login
- `/admin/dashboard` - Admin dashboard
